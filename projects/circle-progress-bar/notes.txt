
- **Call Stack**: Moves on (no code runs yet).  

#### **2. After 20ms (First Iteration)**

  - Moves `callback` from Task Queue → Call Stack.  
- **Call Stack**:  
  - Runs `callback` (`degree++`, DOM updates).  
  - Finishes → Browser **renders UI changes**.  

#### **3. Repeat Every 20ms**
- **Same cycle**:  
  - Web API: Timer *N* → Task Queue → Call Stack.  
  - Each callback is **independent** (no overlap).  

#### **4. Stopping (`clearInterval`)**
- When `degree > targetDegree`:  
  ```javascript

  ```
  - Cancels **all future timers** in Web APIs.  
  - No more callbacks are queued.
