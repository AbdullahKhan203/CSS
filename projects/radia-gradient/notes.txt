its value is default from top to bottom.if we want that it goes from bottom to top, then we can give 
`background-image:linear-gradient(to top,red,yellow,green) ;`
if we want that from left to right then we can give property:-
`background-image:linear-gradient(to right,red,yellow,green) ;`
if we want that from corner to corner, then we can give:-
`background-image:linear-gradient(to right top,red,yellow,green) ;`
we can also angles like:-
background-image:linear-gradient(45deg,red 10%,yellow,green 80%) ;
We can also give colors in rgba:-
we can aslo give repeated liner gradient:-
 background-image:repeated-linear-gradient(to right,rgba(228, 96, 8, 0.5),rgba(100,100,100,0.5)) ;
