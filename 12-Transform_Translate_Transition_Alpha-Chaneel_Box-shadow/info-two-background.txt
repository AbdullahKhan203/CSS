## 🧱 **What is the `background` Property in CSS?**

The `background` property in CSS is a **shorthand** that lets you apply multiple background styles (like color, image, position, etc.) all in **one line**.

It affects the **background layer** of an element (behind content, padding, and borders).

---

## ✍️ **Full Syntax:**
```css
background: color image position / size repeat origin clip attachment;
```

But you don't have to use all parts. You can write just what you need.

---

## 🔍 **Individual Background Properties Explained**

| Property               | What It Does                                      | Example                          |
|------------------------|---------------------------------------------------|----------------------------------|
| `background-color`     | Sets the background color                         | `background-color: lightblue;`   |
| `background-image`     | Sets an image as the background                   | `background-image: url("bg.jpg");` |
| `background-position`  | Sets position of background image                 | `center`, `top left`, `50% 50%`  |
| `background-size`      | Controls image size (auto(default),`cover`, `contain`, or px)  | `background-size: cover;`        |
| `background-repeat`    | Repeats image (`repeat`, `no-repeat`, etc.)       | `background-repeat: no-repeat;`  |
| `background-attachment`| Scroll behavior (`scroll` or `fixed`)            | `background-attachment: fixed;`  |
| `background-origin`    | Where background is positioned from               | `padding-box`, `border-box`      |
| `background-clip`      | How far the background extends                    | `content-box`, `padding-box`     |

---

## 🎯 **Shorthand Example:**
```css
div {
  background: #f0f0f0 url("bg.jpg") no-repeat center/cover fixed;
}
```

🔹 This sets:
- Background color to light gray
- Background image (`bg.jpg`)
- No repeat
- Centered
- Image covers the area
- Fixed while scrolling

---

## ✅ **Basic Examples**

### 1. **Just a Background Color**
```css
div {
  background-color: #ffcc00;
}
```

---

### 2. **Background Image**
```css
div {
  background-image: url('sunset.jpg');
  background-repeat: no-repeat;
  background-size: cover;
}
```

---

### 3. **Parallax Scroll Effect**
```css
div {
  background: url('mountains.jpg') no-repeat center center fixed;
  background-size: cover;
}
```

Creates a **"frozen background"** while content scrolls.
