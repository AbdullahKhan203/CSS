Ans:-# CSS Variables (Custom Properties) - Complete Guide

CSS variables, officially called "CSS Custom Properties," allow you to store and reuse values throughout your stylesheets. Here's a detailed explanation:

## Basic Syntax

```css
/* Define a variable */
:root {
  --main-color: #06c;
  --default-padding: 16px;
}

/* Use a variable */
.element {
  color: var(--main-color);
  padding: var(--default-padding);
}
```

## Key Features

1. **Scoping**: Variables can be defined at different scopes
   - `:root` for global variables (HTML element)
   - Specific selectors for local variables

2. **Fallback Values**: You can specify fallback values
   ```css
   .box {
     background: var(--box-bg, #f8f8f8);
   }
   ```

3. **Dynamic Updates**: Variables can be changed with JavaScript
   ```javascript
   document.documentElement.style.setProperty('--main-color', 'red');
   ```

## Practical Examples

### 1. Theming
```css
:root {
  --primary: #4285f4;
  --secondary: #34a853;
}

.dark-theme {
  --primary: #1a73e8;
  --secondary: #0b8043;
}

.button {
  background: var(--primary);
  color: white;
}
```

### 2. Responsive Design
```css
:root {
  --gutter: 16px;
}

@media (min-width: 768px) {
  :root {
    --gutter: 24px;
  }
}

.container {
  padding: var(--gutter);
}
```

### 3. Complex Calculations
```css
:root {
  --base-size: 16px;
  --scale: 1.2;
}

h1 {
  font-size: calc(var(--base-size) * var(--scale) * 2);
}
h2 {
  font-size: calc(var(--base-size) * var(--scale));
}
```

## Advanced Usage

### 1. Variable Chains
```css
:root {
  --primary: #06c;
  --button-bg: var(--primary);
}
```

### 2. Using Variables with calc()
```css
:root {
  --spacing: 10px;
}

.element {
  margin: calc(var(--spacing) * 2);
}
```

### 3. Animating Variables
```css
@property --angle {
  syntax: '<angle>';
  inherits: false;
  initial-value: 0deg;
}

.element {
  --angle: 0deg;
  transition: --angle 1s;
}

.element:hover {
  --angle: 360deg;
}
```

## Browser Support

CSS variables are supported in all modern browsers (Chrome, Firefox, Safari, Edge) since approximately 2016. Internet Explorer 11 does not support them.

## Best Practices

1. Use meaningful names (--main-color rather than --mc)
2. Organize variables logically (colors, spacing, typography)
3. Document your variables with comments
4. Consider using a naming convention like BEM for variables
   ```css
   --button__background-color: #06c;
   ```

## JavaScript Interaction

```javascript
// Get variable value
const color = getComputedStyle(document.documentElement)
  .getPropertyValue('--main-color');

// Set variable value
document.documentElement.style
  .setProperty('--main-color', 'red');

// Remove variable
document.documentElement.style
  .removeProperty('--main-color');
```

CSS variables are extremely powerful for creating maintainable, flexible stylesheets and enabling dynamic theming in web applications.

Ans:-Let me break down each of your questions about CSS variables in detail:

## 1. How to Define a CSS Variable

```css
/* Syntax */
selector {
  --variable-name: value;
}

/* Example */
:root {
  --main-color: #3498db;
  --default-padding: 16px;
}
```

## 2. Defining Variables in Specific Rules (.container or h2)

When you define a variable within a specific selector:

```css
.container {
  --container-bg: #f1f1f1;
  background: var(--container-bg);
}

h2 {
  --heading-color: #2c3e50;
  color: var(--heading-color);
}
```

**What happens:**
- The variable is only available to that selector and its children
- It's not available to sibling elements or parent elements
- This is called "scoping" in CSS variables

## 3. Purpose of Defining Variables in `:root{}`

The `:root` selector targets the highest-level parent in the DOM (equivalent to `html` but with higher specificity):

```css
:root {
  --primary-color: #3498db;
}
```

**Why use :root?**
- Makes variables globally available to all elements
- Acts as a "single source of truth" for design tokens
- Can be easily overridden for theming purposes
- Follows the principle of separation of concerns

## 4. How to Override Root Variables

You can override root variables at any level:

```css
:root {
  --main-color: blue;
}

.container {
  --main-color: red; /* Overrides for .container and its children */
}

.special-item {
  --main-color: green; /* Further override */
}
```

## 5. Providing Fallback Values

Syntax:
```css
property: var(--variable-name, fallback-value);
```

Examples:
```css
.box {
  /* Single fallback */
  color: var(--text-color, black);
  
  /* Multiple fallbacks */
  padding: var(--space-small, var(--space-base, 10px));
  
  /* Fallback with calc() */
  width: calc(var(--container-width, 100%) - 20px);
}
```

## 6. Inheritance Flow of Variables

CSS variables follow normal CSS inheritance:

1. Browser checks if variable is defined on the element itself
2. If not found, looks at the parent element
3. Continues up the DOM tree until reaching `:root`
4. If still not found, uses the fallback value (if provided)
5. With no fallback, uses the initial value for that CSS property

Example:
```html
<div class="grandparent" style="--color: red;">
  <div class="parent">
    <div class="child"></div>
  </div>
</div>
```
```css
.child {
  color: var(--color); /* Inherits red from grandparent */
}
```

## 7. What Happens with Invalid Property-Variable Combinations

```css
:root {
  --rounded: 24px;
}

.box {
  color: var(--rounded); /* Invalid - using a length value for color */
}
```

**Behavior:**
1. The browser tries to use `24px` as a color value
2. Recognizes it's invalid for the `color` property
3. Falls back to:
   - The inherited color if one exists
   - The default color (usually black) if no inheritance
4. **Does not** trigger a CSS error - the rule is simply ignored for that property

**Important Notes:**
- The invalid declaration won't break other CSS rules
- No warning appears in browser consoles
- This is why type checking is important with CSS variables
- Some newer CSS features like `@property` can help enforce types

## Practical Example Combining All Concepts

```css
:root {
  --primary-color: #3498db;
  --text-size: 16px;
}

header {
  --primary-color: #2c3e50; /* Overrides root variable */
  background: var(--primary-color);
  font-size: var(--text-size);
}

button {
  color: var(--primary-color);
  border-radius: var(--button-radius, 4px); /* Fallback */
  padding: var(--button-padding, 10px 20px);
}

.special-button {
  --button-radius: 10px; /* Overrides fallback */
  border: var(--button-border, 1px solid currentColor); /* Complex fallback */
}
```

CSS variables are incredibly powerful but require careful planning to avoid unexpected results, especially with invalid value combinations.

## **2. CSS (style.css)**
```css
/* Root variables (global scope) */
:root {
  --primary-color: #3498db;
  --secondary-color: #2ecc71;
  --text-size: 16px;
  --container-width: 100%;
  --spacing-unit: 16px;
}

/* Header overrides root variable */
.site-header {
  --primary-color: #2c3e50; /* Override */
  background: var(--primary-color);
  color: white;
  padding: var(--spacing-unit);
  font-size: var(--text-size);
}

/* Button with fallbacks */
.btn {
  --btn-radius: 4px; /* Local variable */
  color: var(--primary-color);
  background: white;
  border: var(--btn-border, 1px solid currentColor);
  border-radius: var(--btn-radius);
  padding: var(--btn-padding, 8px 16px);
  font-size: calc(var(--text-size) * 0.9);
  margin: calc(var(--spacing-unit) / 2);
  cursor: pointer;
}

/* Special button overrides fallback */
.special-btn {
  --btn-radius: 10px; /* Override local variable */
  --btn-padding: 12px 24px;
  background: var(--primary-color);
  color: white;
}

/* Size calculation demo */
.resizable-box {
  width: calc(var(--container-width, 100%) - 20px);
  height: 100px;
  background: var(--secondary-color);
  margin: var(--spacing-unit) 0;
  transition: width 0.3s;
}

/* Invalid property demo */
.broken-box {
  color: var(--box-roundness, 8px); /* Invalid: using length for color */
  background: lightgray;
  padding: var(--spacing-unit);
  border-radius: var(--box-roundness, 8px); /* Valid use of same variable */
}

## **3. JavaScript (script.js)**
```javascript
document.addEventListener('DOMContentLoaded', () => {
  const root = document.documentElement;
  const primaryColorInput = document.getElementById('primaryColor');
  const textSizeInput = document.getElementById('textSize');
  const resetBtn = document.getElementById('resetBtn');

  // Update primary color variable
  primaryColorInput.addEventListener('input', (e) => {
    root.style.setProperty('--primary-color', e.target.value);
  });

  // Update text size variable
  textSizeInput.addEventListener('input', (e) => {
    root.style.setProperty('--text-size', `${e.target.value}px`);
  });

  // Reset all variables
  resetBtn.addEventListener('click', () => {
    root.style.removeProperty('--primary-color');
    root.style.removeProperty('--text-size');
    primaryColorInput.value = '#3498db';
    textSizeInput.value = '16';
  });
});
```
