### ✅ **2. Card Container**

```css
.card {
  background: #1e1e1e;
  padding: 2rem;
  border-radius: 20px;
  width: 320px;
  text-align: center;
  position: relative;
  overflow: hidden;
  box-shadow: 0 0 30px rgba(0,0,0,0.5);
}
```

* **Rounded, centered card**.
* `position: relative` is important to allow **absolute positioning** of `::before` and `::after` elements inside.
* `overflow: hidden` hides anything going outside the border (used later in hover effect).

---

### ✅ **3. Profile Picture**

```css
.profile-pic {
  width: 100px;
  height: 100px;
  background: url('https://via.placeholder.com/100') no-repeat center/cover;
  margin: 0 auto;
  border-radius: 50%;
  position: relative;
}
```

* Makes a **circular profile picture** using `border-radius: 50%`.
* Uses a placeholder image.
* `position: relative` is again needed for pseudo-elements (`::before`, `::after`).

---

### 🎯 **4. Glow Effect Using `::before`**

```css
.profile-pic::before {
  content: "";
  position: absolute;
  top: -10px;
  left: -10px;
  width: 120px;
  height: 120px;
  background: radial-gradient(circle, cyan, transparent);
  border-radius: 50%;
  z-index: -1;
}
```

* `::before` creates a **glow ring** behind the profile picture.
* `content: ""` is **required** for `::before` to render.
* `radial-gradient` simulates a glowing effect.
* `z-index: -1` ensures it sits behind the image.

---

### 🎯 **5. Hover Pulse Using `::after`**

```css
.profile-pic::after {
  content: "";
  position: absolute;
  top: 0;
  left: 0;
  width: 100px;
  height: 100px;
  border-radius: 50%;
  box-shadow: 0 0 15px cyan;
  opacity: 0;
  transition: opacity 0.3s ease;
}

.profile-pic:hover::after {
  opacity: 1;
}
```

* `::after` adds a **box-shadow ring** on hover.
* `opacity` changes on hover to show the glow.
* `transition` makes the appearance **smooth**.

### 🎯 **7. Bio Text with `::first-letter`**

```css
.bio {
  font-size: 0.95rem;

  text-align: left;

.bio::first-letter {
  font-size: 2rem;
  color: cyan;
  font-weight: bold;
}
```

* The paragraph `.bio` has normal text.
* `::first-letter` **targets the first letter** and makes it big and bold — like a "drop cap".

### 🎯 **8. Skills List with Custom `::marker`**

```css
.skills {
  list-style: square;
```

* `::marker` changes the color and size of the **bullet points** for list items.
* This is often underused and very powerful in custom designs.

### 🎯 **11. File Upload Button using `::file-selector-button`**

```css

  background: cyan;
  color: black;
  border: none;
  padding: 0.5rem 1rem;
  border-radius: 8px;
  cursor: pointer;
}
```

* `::file-selector-button` lets you **style the button** inside `<input type="file">`.
* This is very useful since it's normally hard to style natively.
