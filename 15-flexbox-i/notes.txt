---

### Understanding CSS `width: max-content` and `min-content`

- `width: max-content;`  
  This makes the container **as wide as the longest line of content**. All content stays in **one line**, and the width grows to fit it.
  
- `width: min-content;`  
  This keeps each **word on a new line**, so the container becomes as **narrow as the longest word**.

**Example for `min-content`:**
```
i  
am  
Pakistani.
```
Here, the container width is just enough to fit the longest word: **"Pakistani"**.

---

### Flexbox Basics

- When you make a container a **flex container**, its children become **flex items**.
- These items appear **in one line** (horizontally by default), but they **don’t behave like block elements** (they don’t fill the full line unless specified).
  
#### Inline vs Flex
- Normally, we **can’t set width or height** on inline elements.
- But when an inline element becomes a **flex item**, we **can apply height and width** to it, just like a block element.

---

### Resetting Default Styles

To remove default margins and paddings from elements and get full control, use this CSS:

```css
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
```

---

### How Flex Items Use Space

- If a flex container has multiple items **without fixed widths**, the items will size themselves based on their content.

Example:
```html
<div class="flex-container">
  <div>Item 1</div>
  <div>Longer Item 2</div>
  <div>Item 3</div>
</div>
```
Each item will take up space according to its content.

#### Giving Widths

- If you **assign widths** (like 200px, 400px, 400px), they will take up that much space **if available**.
- If the container **doesn’t have enough space**, the items **shrink equally**.

Example:
- Given widths: 200px, 400px, 400px → Total: 1000px
- If the container only has 800px width, all items shrink **proportionally**:
  - 200px → 100px  
  - 400px → 350px (and so on...)

---

### Preventing Flex Items from Shrinking

If you **don’t want a flex item to shrink**, use:

```css
flex-shrink: 0;
```

This will make the item keep its original width, and the other items will shrink instead.

---

### Using `flex-grow` for Extra Space

If you want flex items to **use extra space**, use `flex-grow`.

Example:

- Container width: 1200px  
- Three items with widths: 200px + 400px + 400px = 1000px  
- 200px is left unused.

You can distribute that 200px extra like this:

```css
/* Grow ratio: 75px, 50px, 75px out of total 200px */
.flex-item-1 { flex-grow: 0.375; }
.flex-item-2 { flex-grow: 0.25; }
.flex-item-3 { flex-grow: 0.375; }
```

This will give more space to item 1 and 3, and less to item 2.
