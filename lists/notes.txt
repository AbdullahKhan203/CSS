### **📌 Lists in CSS – Complete Guide**  

In **CSS**, lists are used to **style ordered (`<ol>`) and unordered (`<ul>`) lists**. You can control how bullet points (or numbers) appear, change their position, add custom icons, and much more!  

---

## **1️⃣ Types of Lists in HTML**  
Before styling lists in CSS, let's understand the **three types of lists** in HTML:

| **List Type** | **Tag** | **Example** |
|--------------|--------|------------|
| **Unordered List** | `<ul>` | 🔹 Bullet points |
| **Ordered List** | `<ol>` | 1️⃣ Numbered list |
| **Description List** | `<dl>` | Term: Definition |

### **Example: Basic Lists in HTML**
```html
<ul>
    <li>Apple</li>
    <li>Banana</li>
    <li>Cherry</li>
</ul>

<ol>
    <li>First Step</li>
    <li>Second Step</li>
    <li>Third Step</li>
</ol>

<dl>
    <dt>HTML</dt>
    <dd>HyperText Markup Language</dd>
    <dt>CSS</dt>
    <dd>Cascading Style Sheets</dd>
</dl>
```

---

## **2️⃣ CSS List Properties**
CSS provides several properties to style lists:

| **Property** | **Description** | **Example Value** |
|-------------|----------------|------------------|
| `list-style-type` | Changes bullet or number type | `disc`, `circle`, `square`, `decimal`, `upper-roman` |
| `list-style-position` | Controls bullet/number position | `inside`, `outside` |
| `list-style-image` | Replaces bullets with an image | `url('icon.png')` |
| `list-style` | Shorthand for all list styles | `square inside url('icon.png')` |

---

## **3️⃣ Styling Lists with CSS**
### **🔹 Changing Bullet Type (`list-style-type`)**
You can change the default bullets in unordered (`<ul>`) and ordered (`<ol>`) lists.

```css
ul {
    list-style-type: square; /* Options: disc, circle, square, none */
}

ol {
    list-style-type: upper-roman; /* Options: decimal, lower-alpha, upper-roman, etc. */
}
```

### **🔹 Changing Bullet Position (`list-style-position`)**
By default, list bullets are **outside** the list item. You can move them **inside**.

```css
ul {
    list-style-position: inside;
}
```
✅ **Inside** makes the bullet part of the text.  
✅ **Outside** keeps the bullet separate.

---

### **🔹 Custom Bullet Using an Image (`list-style-image`)**
Replace default bullets with an **image**.

```css
ul {
    list-style-image: url('custom-bullet.png');
}
```

✅ If the image is too big, you can use **background images instead**.

---

### **🔹 Using `list-style` (Shorthand)**
Instead of writing three separate properties, use `list-style` shorthand.

```css
ul {
    list-style: square inside url('custom-bullet.png');
}
```
📌 **Order of values:** `type position image`

---

## **4️⃣ Removing Default List Styles**
By default, browsers add padding and margins to lists. If you want to **remove bullets or numbers**, use:

```css
ul, ol {
    list-style: none;
    padding: 0;
    margin: 0;
}
```
✅ This removes bullets and resets spacing.

---

## **5️⃣ Styling List Items (`<li>`)**
Each `<li>` can have **custom colors, spacing, hover effects, and more**.

```css
li {
    color: blue;
    font-size: 18px;
    padding: 5px;
}

li:hover {
    color: red;
}
```

---

## **6️⃣ Advanced List Styling – Custom Icons**
If `list-style-image` doesn't work well, use `::before` to add custom **icons or emojis**.

```css
ul li::before {
    content: "✅ "; /* Add an emoji or icon */
    color: green;
    font-size: 20px;
}
```
✅ **Now each list item starts with a ✅ instead of a bullet!**

---

## **🎯 Full Example: Beautiful Styled List**
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Styled Lists</title>
    <style>
        ul {
            list-style: none; /* Remove default bullets */
            padding: 0;
        }

        ul li {
            font-size: 18px;
            padding: 10px;
            border-bottom: 1px solid #ddd;
            position: relative;
        }

        ul li::before {
            content: "✔️ "; /* Custom checkmark icon */
            color: green;
            font-weight: bold;
            font-size: 20px;
            position: absolute;
            left: -25px;
        }

        ol {
            list-style-type: upper-roman; /* I, II, III, IV */
            color: navy;
            font-size: 18px;
        }
    </style>
</head>
<body>

    <h2>Custom Bullet List</h2>
    <ul>
        <li>First Item</li>
        <li>Second Item</li>
        <li>Third Item</li>
    </ul>

    <h2>Ordered List</h2>
    <ol>
        <li>Step One</li>
        <li>Step Two</li>
        <li>Step Three</li>
    </ol>

</body>
</html>
```
✅ **This creates a modern list with checkmarks and styled ordered numbers!**
